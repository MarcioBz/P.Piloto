Administração

Configurações

Defina o ano letivo ativo e exporte uma cópia local dos dados do AlunoTec.

Ano letivo ativo

Os próximos anos ficam disponíveis automaticamente. Escolher outro ano preserva o histórico dos anteriores; cadastre as turmas e matrículas correspondentes ao novo período.

Cópia de segurança

Baixe os dados escolares salvos neste navegador em um arquivo JSON. A cópia inclui turmas, frequências, remanejamentos, notificações, alertas, anexos, professores (incluindo seus códigos locais) e o ano letivo. Ela não inclui tokens de acesso. Guarde o arquivo em local reservado à administração.

Restaurar cópia de segurança

Escolha o JSON exportado pelo AlunoTec. Você poderá desfazer a restauração e recuperar os dados anteriores.

Restaurar os dados desta cópia?

Os cadastros deste navegador serão substituídos pelos dados do arquivo escolhido. A versão atual ficará guardada para desfazer a restauração.
